### Гипотеза оси 1
Спектр памяти агента, выгодный в мире, повторяет спектр временных масштабов мира. Выгода есть при редких свидетельствах и исчезает при частых.

### 1. Среда `env_spectrum.py`
- **Основа flip-2:** два вида; знак «какой вид — пища»; пища +0,35, яд −0,20; навигация — рефлекс к выбранному виду.
- **Скрытые переменные** (1 — «в пользу A»):
  - **s** (быстрая, знак): с вероятностью h_f за такт пересэмплируется. P(s = 1) = p_hi при m = 1, p_lo при m = 0.
  - **m** (средняя): с вероятностью h_m за такт пересэмплируется. P(m = 1) = p_hi при g = 1, p_lo при g = 0.
  - **g** (медленная): с вероятностью h_g за такт меняет значение; в варианте const постоянна за жизнь.
  - «Переворот» понят как пересэмплирование: знак после него может остаться прежним. Иначе m и g не влияли бы на s.
- **Свидетельства.** С вероятностью q за такт агент встречает предметы обоих видов. Рефлекс приводит его к выбранному виду, он съедает его и по исходу (рост или падение энергии) узнаёт s точно — какой бы вид ни выбрал.
- **Мягкое выживание.** Смерти нет, отбора выживших нет. Энергия — утечка к уровню покоя без границ: E ← E − λ (E − E0) + r, λ = 0,01, E0 = 0,5.
- **Жизнь** — 5000 тактов.

**Отступления от программы:**
1. **Пространственная навигация flip-2 сведена к встрече с вероятностью q** и рефлексу к выбранному виду. Причины:
   - в flip-2 рефлекс надёжно доводит до выбранного вида, пространство добавляет только шум;
   - в пространстве частота встреч зависела бы от выбора и от расстановки предметов, а частоту свидетельств программа задаёт как «вероятность встречи за такт».
   - Следствие: поток свидетельств не зависит от политики. Агенты различаются только решениями, миры у всех общие (парные сравнения по жизни). Исследования нет: знак узнаётся при любом выборе.
2. **Энергия без границ.** При ограниченной энергии и редких встречах она сидела бы у нуля или у единицы, и различия срезались бы. Средняя энергия за жизнь = E0 + Σ r_k w(t_k), то есть аффинна по выгодам решений (проверено прямым расчётом утечки: совпадение до 10⁻⁶).

### Сетка (16 конфигураций мира × 3 частоты)
| Параметр | Значения |
| --- | --- |
| h_f | 1/20, 1/50 |
| r = h_m / h_f = h_g / h_m | 1/10, 1/30 |
| g | switch (h_g = r² h_f), const |
| (p_hi, p_lo) — сила иерархии | (0,8; 0,2), (0,9; 0,1) |
| частота свидетельств q = c · h_f | редко c = 0,5, средне c = 2, часто c = 8 (свидетельств на эпоху знака) |
| жизни | 200 обучающих (подбор), 200 отложенных (сравнение); посевы общие для всех агентов |

Эпох за жизнь:
- s — 250 при h_f = 1/20 и 100 при h_f = 1/50;
- m — 25 / 8,3 / 10 / 3,3 (при h_f = 1/20 и r = 1/10 / 1/30, затем при h_f = 1/50);
- g (switch) — 2,5 / 0,28 / 1,0 / 0,11.

**«g меняется за жизнь»** — switch и T·h_g ≥ 1: это hf20_r10_switch и hf50_r10_switch. В остальных switch-конфигурациях g меняется за жизнь в среднем 0,28 и 0,11 раза. Для них условие «L3 − L2» и масштаб τ3 не проверяются: τ3 там неопределим, любой τ3 ≳ T эквивалентен.

### Проверка конструкции (до записи критериев; `python env_spectrum.py --check`, 100 жизней на ячейку)
- **Частота встреч не зависит от m и g:** при m = 1 / 0 — 0,0249 / 0,0254 (редко, hf20); при часто — 0,3989 / 0,4002. Так во всех 48 ячейках в пределах шума.
- **Знак при m = 1 / 0:** доля «A — пища» 0,78–0,91 / 0,10–0,23; при g = 1 / 0 — 0,62–0,85 / 0,16–0,39. AUC «последний знак → m» 0,78–0,90. Это законный канал — история пересэмплирований.
- **Других каналов о m и g нет по построению.** Встречи независимы от скрытых состояний. Наблюдение — только s. Смерти и отбора выживших нет, поэтому «съеденное по выжившим» неприменимо. Последнее событие несёт s и только через него — m и g.
- **Проверка кода на вырожденных мирах:**
  - при h_m = h_g = 0, p = 0,5 байесовский фильтр совпадает с «последним знаком» в 100 % решений;
  - при h_f = 0 после первого наблюдения фильтр всегда прав;
  - L1 с τ = 0,3 совпадает с «последним знаком» в 100 %.
- **Найдена и исправлена до записи ошибка точности.** При редких свидетельствах x − 0,5 уходила ниже машинной точности, и решение систематически становилось «B». Теперь расчёт идёт через d_i = x_i − 0,5, ничья разбивается общей монеткой мира.

### 2. Эвристические агенты (решение на встрече: A, если P(A — пища) > 0,5)
- **Каскад следов.** След i — взвешенное по времени среднее наблюдённых знаков с постоянной τ_i в тактах:
  - S_i ← S_i e^(−Δ/τ_i), N_i ← N_i e^(−Δ/τ_i); при наблюдении S_i += y, N_i += 1.
  - Оценка слоя сжимается к слою выше с псевдосчётом κ = 1: x_L = (S_L + κ·0,5) / (N_L + κ), x_i = (S_i + κ x_(i+1)) / (N_i + κ); P(A) = x_1.
  - Быстрый след — знак; когда свидетельства стареют, вес переходит к медленному следу (смещение), а его — к следующему.
  - Форма следов в программе не задана — это решение исполнителя.
- **Агенты каскада:**
  - **L1** — один след (τ1); **L2** — два (τ1 ≤ τ2); **L3** — три (τ1 ≤ τ2 ≤ τ3).
  - Подбор на обучающих жизнях по средней энергии.
  - L1 и L2 — сетка τ = 10^(0,5 + 0,25k), k = 0…18 (3,2 … 100 000).
  - L3 — грубая сетка с шагом 10^0,5, затем уточнение ± 10^0,25 по каждому слою.
- **L3_mis** — подобранные постоянные L3, изменённые тремя способами: все ×10, все ÷10, обратный порядок. Берётся лучший на обучающих (консервативно).
- **BAYES** — точный фильтр по (g, m, s) с известными частотами (потолок).
- **Реактивный** — без памяти (монетка), нижняя граница.
- **Меры:**
  - средняя энергия за жизнь;
  - выгода на встречу;
  - описательно — точность на первой встрече после невидимой смены знака, где последний знак неверен и помогают только средний и медленный слои (это вместо «первых k тактов после переворота»).

### 3. Критерии (для каждой конфигурации мира; z — по 200 отложенным жизням, парные по жизни)
1. **Барьер:** при «редко» BAYES − L1 > 0, z ≥ 3.
2. **Нужен средний слой:** при «редко» L2 − L1 > 0, z ≥ 3. Если g меняется за жизнь — ещё L3 − L2 > 0, z ≥ 3.
3. **Согласование важно:** при «редко» L3 − L3_mis > 0, z ≥ 3.
4. **Масштабы:** у постоянных L3, подобранных при «редко», |ln(τ1 h_f)| ≤ ln 3 и |ln(τ2 h_m)| ≤ ln 3. Если g меняется за жизнь — ещё |ln(τ3 h_g)| ≤ ln 3.
5. **Условность:** выигрыш L3 − L1 **на встречу** убывает: редко > средне > часто (точечно), и редко − часто > 0, z ≥ 3 (независимые жизни). Мера на встречу — потому что частоты встреч разные, а средняя энергия растёт с числом решений.
6. **Нет вырождения:** при «редко» (L1 − REACT) / (BAYES − REACT) < 0,8.

- Меры 1–3 и 6 — по средней энергии.
- **Версия среды проходит,** если хотя бы одна конфигурация выполняет 1–6.
- **Конфигурация для этапа 2** — с наибольшим L3 − L1 (энергия) на обучающих жизнях при «редко» среди прошедших.
- Уровень строгости — z ≥ 3 на критерий, как в программе. Поправки на 16 конфигураций нет (эвристический этап).

### 4. Толкование (записано заранее; по конфигурациям)
- **1–6 выполнены** — при редких свидетельствах агенту выгодна память, спектр которой повторяет спектр мира, и выгода исчезает при частых свидетельствах. Гипотеза оси 1 поддержана на уровне задачи.
- **2 и 3 выполнены, 4 нет** — слоёв нужно столько, сколько масштабов у мира, но их скорости с масштабами не совпадают. Гипотеза в слабой форме.
- **5 не выполнено** — выгода не зависит от частоты свидетельств: уточнение гипотезы неверно.
- **2 не выполнено** — один след справляется: гипотеза не подтверждена.
- Если ни одна конфигурация не прошла 1–6, версия не прошла. По правилу п. 0 допускается ещё одна версия (только по решению Егора), после неё — вывод из п. 0.

### Известные слабые места (до расчёта)
- **Каскад со сжатием — одна из возможных форм «следов».** Отрицательный исход по критерию 2 означает «этот класс следов не выигрывает», а не «никакая память не выигрывает». BAYES показывает, сколько можно выиграть вообще.
- **Сетка τ дискретна** (шаг 10^0,25 ≈ 1,78, у L3 — после уточнения). Допуск критерия 4 — множитель 3.
- **L3 подбирается в два шага** (грубо, затем локально) и может не найти глобальный оптимум. Тогда L3 недооценён — это работает против критериев 2 и 3.
- **В конфигурациях с r = 1/30 и h_f = 1/50** средняя переменная меняется за жизнь всего 3,3 раза.
