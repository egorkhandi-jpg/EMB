# Записываемый дискретный слот — пререгистрация и результаты

Статус документа: **пререгистрация** (записано и закоммичено до просмотра результатов идущего прогона `v3-readout`; ничего из этого плана не запускалось). Решение Егора 2026-10-02. Всё, что дописано после метки серии, помечается как добавленное после серии.

## Зачем
По итогам A–D (`docs/RESULTS_2026-10-01_flip.md`) предобученная LM работает как **механизм чтения памяти по окну, а не как память**: записи нет, всё старше N тактов теряется. Слот — минимальная запись, которую агент делает сам. Дискретный — потому что предобученный аппарат включается на повторяющихся символах малого алфавита (A: шесть случайных векторов нормы токена в предобученном трансформере — 0,984, лучше слов).

## Конструкция
- Среда `flip-2` с разворотом; рефлекторный слой (голова выбирает вид и скорость, к выбранному виду рулит зашитый рефлекс); Pythia-160M, fp32. Интерфейс — c (события такта словами + BOS), как в пилоте D; e1 (шесть случайных векторов вместо слов) — описательно.
- **Короткое окно N = 4 такта.** После BOS — **одна позиция слота**: эмбеддинг одного символа из собственного алфавита K = 8 случайных векторов нормы токена, плюс символ «пусто» в начале эпизода (тоже случайный вектор нормы токена). Последовательность: BOS, слот, события последних 4 тактов.
- **Запись — только по событию** (зашитый детектор: что-то съедено). В такт события голова записи (линейная по скрытому состоянию последней позиции, K выходов, argmax) выбирает символ, и слот заменяется. В остальные такты слот не меняется.
- ES учит голову выбора (2D + 2) и голову записи (D·K + K) вместе.

## Этап 0 — без обучения (протокол П3, зонд знака)
Условия, предобученная и случайная LM (у случайной — те же символы/токены, матрица приведена к средней норме эмбеддингов предобученной):
- слот с **записью-оракулом**: символ кодирует (вид, исход) последнего события — 4 из 8 символов (A-рост, A-падение, B-рост, B-падение), запись по событию;
- N = 4 без слота;
- N = 32 без слота (ориентир).
Траектории — как в П3 (политика, слепая к знаку; 10 наборов по 200 эпизодов; такты, где знак определим). Зонд — `probe_fast`, цель — знак эпизода, мера — сбалансированная точность по тактам после последнего события k.

**Вопрос этапа 0:** читает ли аппарат знак из слота за пределами окна. **Правило остановки:** если с оракульной записью точность зонда при k > 4 тактах после события не выше, чем без слота (N = 4), — дальше не идти.

Условия:

| слот с ES-записью | предобученная и случайная |
| слот со случайной записью по событию (символ равновероятно из K в такт события) | предобученная и случайная |

| gru с рефлексом (one-hot события такта) | — |

ES — 16 пар × 4 эпизода × 40 поколений; тест — те же 100 эпизодов, что в пилоте D.

**Главная мера:** точность выбора вида на информированных тактах **при k > N = 4 тактов после последнего события** (за пределами окна). Вторичные: та же точность при k ≤ 4; тест; пища / яд.

**«Словарь агента»** (описательно): взаимная информация между записанным символом и (вид, исход) события; энтропия использования символов; устойчивость смысла символа внутри и между эпизодами.

## Статистика
**Основная семья** (Холм; серия 10 посевов; предобученная LM; точные парные перестановки по посевам; двусторонние, α = 0,05 после поправки):
1. ES-слот − без слота, главная мера;
2. ES-слот − слот со случайной записью, главная мера.
Описательно: предобученная против случайной, оракул, gru, N = 32, словарь.

**Правило толкования** (записано заранее):
- (1) > 0 и (2) > 0 — агент переносит знак за окно собственной записью;
- (1) > 0, (2) ≈ 0 — помогает не содержание записи, а сам факт события в слоте;
- оба ≈ 0 при положительном этапе 0 — узкое место в обучении записи (следующий шаг — клонирование записи-оракула + ES).
«≈ 0» — не значимо после поправки.

**Новый вопрос.** Может ли собственная запись агента в слот, которую читает замороженный аппарат LM, заменить быстрые веса как память дальше окна — без обучения при жизни.

### Конструкция
- Среда — `flip-2` с разворотом, без изменений. Рефлекс. Pythia-160M, интерфейс c + BOS, fp32, фиксированная стандартизация по случайному поведению — своя для каждого входа.
- **Окно N = 4 такта:** знак старше 4 тактов из окна не виден. Последовательность: BOS, слот, события последних 4 тактов (по 2 символа).
- **Слот** — одна позиция после BOS: символ из алфавита 8 однотокенных слов (' cat', ' table', ' lamp', ' cloud', ' violin', ' carpet', ' bottle', ' feather') или «пусто» (' stone') в начале эпизода. Однотокенность проверена токенизатором.
- **Запись по правилу органа:** на каждом событии слот заменяется кодом (вид съеденного, исход): A-пища ' cat', A-яд ' table', B-пища ' lamp', B-яд ' cloud'. Исход — по тренду энергии, как метка тела: рост или «без изменения» — пища. Правило не зависит от политики.

**Агенты:**
- `slot_organ` — замороженная голова + слот с записью по правилу органа;
- `slot_random` — то же, но на событии в слот пишется случайный из 8 символов (свой генератор от посева эпизода);
- `noslot` — замороженная голова, окно 4, без слота (нижняя граница);
- `fast` — без слота, окно 4: замороженная голова `noslot` плюс быстрые веса, которые учатся на ходу от тела (нормированное правило A11, η = 0,3, устойчиво при 0 < η < 2, правило 12) и сбрасываются на эпизод; решение — по сумме, как онлайн-тест dual в A13 (память в весах);
- `win32` — замороженная голова, окно 32, без слота (ориентир: память в окне);
- `oracle_sign` — потолок.

**Замороженные головы.** Пакетная логистическая регрессия до сходимости по меткам тела «последний исход» (как A14: λ по CV с группами-эпизодами). Обучается на **жизни развития** посева s — 50 эпизодов слепой политики (500000 + 1000·s + e). Траектории одни для всех агентов, отличается только вход. Тест — на других посевах (100 тестовых эпизодов 999000+k).

**LM:** предобученная — 10 посевов, одна сеть, головы свои на каждый посев; случайная (сеть от посева) — `slot_organ` и `noslot`, описательно.

### Меры
- **Главная** — выбор вида на информированных тактах при k > 4 (k — тактов после последнего события, то есть за пределами окна), **вне контура**: слепая политика на тестовых эпизодах, слот пишется тем же правилом.
- **То же в контуре** (рефлекс) — вторая мера, те же проверки описательно.
- Вторичные: то же при k ≤ 4; тест F; пища / яд.

### Основная семья
lm pretrained c, 10 посевов, точные парные перестановочные тесты по посевам, Холм по трём:
- **P1:** slot_organ − noslot > 0 (одностороний);
- **P2:** slot_organ − slot_random > 0 (односторонний);
- **P3:** slot_organ − fast (двусторонний).

Минимально возможное p: одностороннее 0,001, двустороннее 0,002.

**Толкование (записано заранее):**
- P1, P2 выполнены и P3 ≥ 0 (двусторонний тест не значим или значим в плюс) — память дальше окна может жить во внешней записи, читаемой замороженным аппаратом, без обучения при жизни;
- P1, P2, но P3 < 0 (значимо в минус) — запись работает, но слабее памяти в весах;
- P1 без P2 — помогает метка события, а не её содержание;
- ни P1, ни P2 — аппарат не читает собственную запись дальше окна.

Описательно: предобученная против случайной при slot_organ (аппарат против любой сети); win32 как ориентир; k ≤ 4; в контуре.

**Место в бюджете:** изменение агента, не среды — бюджет не расходуется.

**Замер (правило 5).** Ноутбук: посев предобученной, все агенты — 100 с; случайная, 2 агента — 35 с на посев. Весь опыт ≈ 25 мин — ноутбук (≤ 4 ч).
