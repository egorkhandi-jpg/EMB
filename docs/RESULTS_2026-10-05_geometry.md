# Тезис 5 (геометрия): разделение «я / мир» через следствия собственных действий

Этап 1 — эвристики на CPU ноутбука; этап 2 — анализ LM без обучения (только если этап 1 прошёл). Бюджет среды не расходуется: нет ни ES, ни обучаемого агента. Код этапа 1 — `env_geo.py`, `geo_precheck.py`; результаты — `results_geo/`.

## Пререгистрация (записано и закоммичено до расчёта)

### Вопрос
Использует ли агент знание собственных действий, чтобы отделить изменения мира от изменений, вызванных собой? И делает ли это предобученный аппарат LM через собственное предсказание следующего события: низкая неожиданность — «я», высокая — «мир»?

### Среда (`env_geo.py`, новая; старые среды не тронуты)
- Арена [0, 1]², тело с курсом. Действие кадра: поворот влево / вправо / нет (± TURN_G = 0,3 рад) и движение вперёд на VMAX = 0,03 или стоять. Стены останавливают тело (тогда предсказание сдвига от своего действия ошибается — это свойство мира).
- K предметов, **ровно один живой**: смещается сам — блуждание с инерцией ρ = 0,95, типичный шаг U, отражение от стен. Остальные неподвижны. Живой — пища, неподвижные — пустышки.
- Раунд: все предметы ставятся заново в [0,1; 0,9]², живой — случайный номер. Раунд кончается, когда живой съеден (дистанция < 0,05) или прожил L_food тактов: пища потеряна, «стоять долго — терять пищу». Касание пустышки переставляет её в новое место.
- Энергия: DRIFT 0,012, пища +0,35, E0 0,6, мягкое выживание. Жизнь — L = 1000 тактов. **Главная мера — число съеденных за жизнь.** Эвристики энергию не читают, а счёт не сжимается потолком энергии. Средняя энергия — описательно.
- **Датчики строго в собственных координатах:** для каждого предмета направление b (0 — прямо, + — влево) и дистанция d, с шумом σ_b = 0,02 рад, σ_d = 0,01; плюс событие «предмет появился заново». Ничего в мировых координатах. Шум введён по построению: без него неподвижный предмет при стоянии не сдвигается вовсе, и «замри и смотри» за один кадр так же точен, как вычитание своего действия. Шум не входит в сетку.
- **Азбука событий кадра (для этапа 2):** своё действие и для каждого предмета сдвиг направления влево / вправо / нет по одному порогу для любой причины сдвига. Порог и слова фиксируются в дополнении до расчёта этапа 2.
- Сетка, 27 конфигураций: K ∈ {2, 3, 4}; U ∈ {0,002; 0,004; 0,008}; L_food ∈ {50, 100, 200}. Сдвиг направления живого от собственного движения при d ≈ 0,4 — 0,005–0,02 рад. Это меньше сдвига от своего поворота (0,3 рад) и от параллакса своего шага (до ≈ 0,07 рад) и сравнимо с шумом.
- Посевы: расстановки, номер живого, шум блуждания и датчиков — таблицы от посева, общие у всех политик.

### Эвристики (`geo_precheck.py`)
Скелет общий. У каждого предмета есть счёт «живой». Цель — предмет с наибольшим счётом, если он выше порога θ_s, иначе ближайший. Курс на цель: поворот, если |b| > TURN_G / 2; вперёд, если |b| < π/2. Появление предмета заново обнуляет его счёт. Накопление остатка: S ← λ R S + r (R — поворот кадра по своей модели: известный у EFF, оценённый у COMMON), счёт = |S|. λ ∈ {0,9; 0,97; 1}, θ_s ∈ {0,01; 0,02; 0,04; 0,08}.
- **R0** — к ближайшему, без памяти.
- **FZ** «замри и смотри» — стоять k тактов без поворота, затем к предмету с наибольшим смещением за стоянку. Повтор после P тактов движения и после любого появления предмета. k ∈ {2, 4, 8, 16}, P ∈ {10, 20, ∞}.
- **NOEFF** — история событий без своих действий: затухающий счёт событий |Δb| > θ_ev, θ_ev ∈ {0,01; 0,02; 0,04}; цель — наибольший счёт, если он больше второго на m ∈ {0,5; 1; 2}.
- **COMMON** — опора на мир без знания своих действий: общий сдвиг всех предметов считается своим. Варианты: `med` (медиана сдвига направления и дистанции); `rigid` (жёсткое преобразование по всем предметам, МНК — «зрительная одометрия»); `robust` (то же, затем без предмета с наибольшим остатком, если остаётся ≥ 2). Остаток копится как «живой». Вариант — часть сетки семьи.
- **EFF** — история + свои действия: предсказанное положение неподвижного предмета после своего действия (поворот на −turn·TURN_G, сдвиг на −move·VMAX вдоль оси). Остаток копится как «живой». Проверка кода: без шума остаток неподвижных ≤ 10⁻¹⁵.
- **EFFC** — то же с грубой моделью кинематики: поворот × {0,7; 1,3}, шаг × {0,5; 1,5} (правило 6).
- **O** — оракул: к живому.

**Протокол.** На точку — 200 жизней. Параметры каждой семьи подбираются по среднему на обучающих посевах 80000–80199. Все сравнения и z — на отложенных 81000–81199, попарно, z = среднее разности / ст. ошибку. B* — наибольшая из трёх баз (FZ, NOEFF, COMMON) по среднему **на отложенных**: так консервативно для критерия 2.

### Критерии (для каждой конфигурации)
1. **Барьер:** O − R0 > 0, z ≥ 3.
2. **Знание себя нужно:** EFF − B* > 0, z ≥ 3, и (EFF − B*) / (O − B*) ≥ 0,5.
3. **Нет вырождения:** (а) (FZ − R0) / (O − R0) < 0,5; (б) (COMMON − R0) / (O − R0) < 0,5; (в) классификатор «живой» по величине сдвига направления в одном кадре |Δb|: AUC ≤ 0,6 и в кадрах политики R0, и в кадрах случайной политики RND (поворот влево / нет / вправо с вероятностями 0,25 / 0,5 / 0,25, движение с вероятностью 0,7; та же политика порождает траектории этапа 2), на отложенных посевах.
4. **Путь (правило 6):** EFFC − B* > 0, z ≥ 2.

**Конфигурация проходит**, если выполнены 1–4. **Для этапа 2** берётся конфигурация с наибольшим запасом по критерию 2 **на обучающих посевах** среди прошедших. Запас — разность «среднее EFF − наибольшее из средних FZ, NOEFF, COMMON» на обучающих (съеденных за жизнь). **Если не проходит ни одна — СТОП**, вывод: «в этой постановке разделение я / мир достигается без знания собственных действий» с указанием пути (FZ, COMMON, величина сдвига — по тому, какой из 3а–3в или 2 не выполнен).

Множественность: 27 конфигураций при z ≥ 3 (одностороннее p ≈ 0,0013, × 27 ≈ 0,036). Прохождение требует одновременно 1–4, поэтому отдельной поправки нет; это оговорено.

Статус: выводы о среде при 200 жизнях и отложенных посевах — «установлено» для эвристик; о LM — только после этапа 2.

## Этап 2 — пререгистрация в общих чертах (выполняется, только если этап 1 прошёл)
Словарь азбуки, порог сдвига, длина окна (16–32 кадра по замеру правила 5) и слои зонда фиксируются **дополнением до расчёта этапа 2**, после выбора конфигурации и замера времени. Меры, семья и толкование фиксируются сейчас:
- Pythia-160M, предобученная и случайная (сеть сеется от набора), fp32, ноутбук. Траектории — политика RND (слепа к тому, какой предмет живой), 10 наборов. Вход — азбука событий кадра + BOS, неперекрывающиеся окна.
- **M1** — неожиданность модели: −log p пришедшего события сдвига предмета (нормировано по трём символам сдвига) по предсказанию с прошлой позиции; средняя неожиданность предмета по окну → AUC «живой против неподвижного».
- **M2** — AUC неожиданности, разделяющей сдвиги, вызванные собой (событие неподвижного предмета, отличное от «нет»), и сдвиги, вызванные миром (событие живого, отличное от того, что показал бы неподвижный предмет в том же месте при том же действии); разметка по истинной причине.
- **M3** — линейный зонд «живой» по скрытому состоянию на символе предмета в последнем кадре окна, логистическая регрессия, кросс-валидация с группами-наборами.
- Абляции: собственные действия заменены нейтральным символом (длина та же); перемешанные кадры.
- Описательно: азбука состояний (направления к предметам, квантованные по углу) против азбуки событий (проверка A8 на геометрии); уровни эвристик как ориентиры.
- **Основная семья** (точные парные перестановки по 10 наборам, односторонние, Холм по трём): G1 — M1 предобученной с действиями > M1 предобученной без действий; G2 — M1 предобученной > M1 случайной; G3 — M3 с действиями > M3 без действий.
- **Толкование:** G1 и G2 — предобученный аппарат через собственное предсказание отделяет мир от себя, используя знание своих действий; G1 без G2 — знание своих действий используется, но не благодаря предобучению; G3 без G1 — разделение есть в переработке прошлого, но не в предсказании; ничего — аппарат не отделяет мир от себя в этой форме. Если M1 с перемешанными кадрами не хуже, чем без перемешивания, — модель опирается на частоты символов, а не на связь «действие → следствие»; это записывается как ограничение толкования.

### Дополнение 1 — опора на мир
Повод: в разборе оптического потока H_common соответствует основному зрительному механизму — глобальному вычитанию потока от собственного движения. Знание собственного движения помимо зрения добавляет к нему: вестибулярные сигналы у макак (PMC7545062), направление ходьбы у людей (HKU 10722/235271). **H_common — не вырождение.**
- Критерий 3б (H_common закрывает < 50 % разрыва) — убран как условие провала, остаётся описательно.
- Новый фактор «опора на мир»: число неподвижных предметов (0, 1, 2, 3) и шум их событий (сетка). При 0 неподвижных опоры нет вовсе.
- Критерий 2 переформулирован. Вклад знания себя D = H_eff − max(H_noeff, H_common, FZ) растёт при ослаблении опоры на мир: монотонный тренд D по числу неподвижных предметов (от многих к нулю), z ≥ 3 для разности D(0 или 1 неподвижный) − D(3 неподвижных). Плюс при слабой опоре D > 0, z ≥ 3, и H_eff закрывает ≥ 50 % разрыва до O.
- Выбор конфигурации для этапа 2 — слабая опора (наибольший D на обучающих посевах среди прошедших); описательно — та же конфигурация с богатой опорой.
- Этап 2: к G1 добавлена описательная проверка — вклад собственных действий в неожиданность (M1 с действиями − M1 без действий) при слабой и богатой опоре. Ожидание: при богатой опоре вклад меньше.
- Толкование: тренд есть — агент, как и зрение, опирается на мир, а знание себя добирает там, где мира мало; тренда нет — знание себя либо не нужно, либо нужно всегда одинаково.

### Дополнение 2 — поворот связи «действие → следствие»
Повод: при повёрнутой зрительной обратной связи нарушается восприятие собственного действия, но не зрительное восприятие (srep25847); уверенность «это сделал я» падает при больших расхождениях предсказанной и реальной обратной связи (модель с латентной переменной авторства, core.ac.uk/works/314206).
- Манипуляция: в случайный момент эпизода без предупреждения меняется отображение собственного поворота в сдвиги предметов — зеркальное или с изменённой величиной (сетка из двух вариантов).
- Этап 1, описательно: H_eff с фиксированной кинематикой (не перестраивается), H_eff_adapt (онлайн-переоценка связи действие → сдвиг), H_common (к повороту нечувствительна).
- Этап 2, новые меры (описательно, кроме Q-R1):
  - волна ложных «живых» — доля неподвижных предметов, классифицированных как живые (по M1 и по зонду M3), по тактам после поворота;
  - время восстановления — тактов до возврата AUC «живой» к уровню до поворота, в сравнении с длиной окна: ≈ окно — пассивное забывание, заметно меньше — перестройка по контексту;
  - с действиями в окне и без них; предобученная и случайная.
- В основную семью добавлено (Холм по четырём): **Q-R1** — рост доли ложных «живых» в первые N тактов после поворота у предобученной с действиями больше, чем то же без действий.
- Толкование: Q-R1 — агент различает мир через предсказание своих действий (поворот ломает именно этот канал); нет Q-R1 при положительном G1 — агент опирается на мир, а знание о действиях влияет иначе.

## Уточнения (ответы Егора; записано до расчёта по дополнениям)
**Среда — `env_geo.GeoBodies2`.** Исходный класс `GeoBodies` не тронут; добавлен только параметр `wall_block` с прежним умолчанием.
- **Кандидаты — всегда два:** живой (снос с инерцией, как раньше) и пустышка, которая **дрожит на месте без сноса**: o_t ~ N(0, (U/2)²) на ось вокруг «дома». Покадровый шаг пустышки того же распределения, что у живого, поэтому величина сдвига в одном кадре их не различает (3в — по построению); различает только накопление. Касание пустышки переставляет её. Угадывание — 1/2 при любом числе ориентиров.
- **Опора на мир — 0–3 неподвижных ориентира** известного непищевого вида: стоят всю жизнь, не цели, сквозь них можно пройти. Шум датчиков ориентиров × {1, 2, 4} (σ_b 0,02 / 0,04 / 0,08 рад, σ_d так же); у кандидатов шум прежний. При 0 ориентиров опоры нет вовсе. Ориентиры видны отдельным каналом.
- **Стена:** шаг за стену не выполняется, тело знает исполненное движение (событие «стою»). Знание своих действий = команда поворота + исполненный шаг.
- **Поворот связи:** с такта t_switch (таблица посева, равномерно 300–700) фактический поворот тела = g × команда, g ∈ {−1 (зеркало), 2}, до конца жизни, без сигнала.
- L_food зафиксирован = 100: не входит в гипотезу и экономит время (решение исполнителя). U ∈ {0,002; 0,004; 0,008}. Конфигураций 30: 3 U × (0 ориентиров + 3 числа × 3 шума).
- Посевы: обучающие 82000–82199, отложенные 83000–83199 (новые, не пересекаются с исходным прогоном). Миры кандидатов одинаковы при любом числе ориентиров (отдельные потоки), поэтому разности между конфигурациями тоже попарны по жизням.

**Эвристики — `geo2_precheck.py`.** Семьи и сетки прежние, все на кандидатах. COMMON видит и кандидатов, и ориентиры; варианты: med, rigid, robust и новый lm (жёсткое преобразование только по ориентирам, если их ≥ 2, иначе по всем). EFFC — прежняя грубая кинематика.

**Критерии по дополнению 1 — для каждой ячейки (U, шум ориентиров).** Число ориентиров 0–3; конфигурация без ориентиров общая для всех шумов. D(n) = EFF − B*(n) по жизням, где B*(n) — наибольшая на отложенных из FZ, NOEFF, COMMON (каждая подобрана на обучающих) при n ориентирах.
1. **Барьер** при слабой опоре: O − R0 > 0, z ≥ 3.
2. **Тренд:** D(0) − D(3) или D(1) − D(3) > 0 с z ≥ 3 (попарно по жизням) **и** монотонность от многих к нулю: на шагах 3 → 2 → 1 → 0 каждый D(n) − D(n + 1) ≥ 0 или z > −2. **Плюс при слабой опоре:** D > 0, z ≥ 3, и (EFF − B*) / (O − B*) ≥ 0,5. Слабая опора — 0 или 1 ориентир, тот, у которого D на обучающих больше.
