# Реестр попыток

Каждая версия среды, каждый пилот и каждый вариант из диагностики — с датой, кодом, критериями и исходом, включая неудачные. В итоговых отчётах указывать число испробованных вариантов. Правило остановки этапа 2 — в `docs/PLAN.md` (не больше двух новых вариантов среды сверх перечисленных).

Обозначения исхода: **прошёл** / **не прошёл** / **только эвристики** (ES не запускалась) / **анализ** (не среда).
