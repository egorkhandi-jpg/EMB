# Этап 3: непрерывная жизнь со сном — «время как ресурс»

## Предварительные проверки эвристиками — пререгистрация (записано до расчёта)
Решение Егора 2026-10-04 после `v4-copies`. Среда — новый вариант `env_sleep.py` (`env_flip.py` не тронут), проверки — `sleep_precheck.py`, без ES и без LM. В `ATTEMPTS.md` — новая среда этапа 3. Слот бюджета расходуется только при запуске ES-пилота.

### Среда
- Физика `flip-2`: два вида по 2 предмета, пища +0,35, яд −0,20, дрейф 0,012 за такт, E0 0,6, рефлекс к ближайшему предмету выбранного вида.
- **Непрерывная жизнь** L = 1000 тактов, без сброса эпизодов; смерть заканчивает жизнь.
- **Развороты знака** в случайные такты, вероятность 1/100 за такт (в среднем раз в 100 тактов). Начальный знак — монетка. Поток разворотов у всех политик общий (свой генератор на жизнь).
- **«Спать k тактов»:** стоит, не ест, энергия падает как обычно, сон не прерывается.
- **Давление сна** — число съеденных предметов с конца последнего сна; для азбуки LM — символ по порогам 1 / 3 / 6.
- **Приспособленность жизни:** F = t_alive / L + 0,5 · Ē, где Ē — средняя энергия по L тактам (после смерти — 0).
- 200 жизней на точку, посевы 40000+i, общие у всех политик: разности считаются попарно.

### Модель агента для эвристик (без LM)
Выбор вида:
1. быстрая память действует — её знак;
2. иначе медленная память, если она есть, — её знак;
3. иначе — к ближайшему предмету любого вида.
- **Быстрая память** — знак, следующий из последнего исхода (съел вид X: пища или яд). Держится τ тактов после события, потом гаснет — это модель затухания быстрой части с постоянной времени τ.
- **Медленная память (M1, по программе)** — правило «последний исход», которое обновляется **только во сне**. В конце сна длиной k с вероятностью p(k) = 1 − e^{−k/κ} медленная память принимает знак последнего исхода, известного к началу сна; иначе не меняется. κ — постоянная консолидации.
- **Основная конфигурация (до расчёта):** τ = 10 тактов (меньше типичного промежутка между съеденными предметами ~12–16 тактов), κ = 10 тактов. Чувствительность (описательно): τ ∈ {5, 10, 20, 40, ∞}, κ ∈ {5, 10, 20}.
- **Известное ограничение M1 (записано до расчёта).** В M1 медленная память хранит сам **знак**, поэтому без сна она устаревает и сон нужен регулярно. У LM-агента медленные веса хранят **правило считывания** знака из окна. Однажды выученное правило не устаревает, и нужда во сне может быть только ранней (выучить правило), а не регулярной. Поэтому описательно добавлена модель **M2**:
  - медленное считывание учится во сне: качество q = 1 − e^{−C/C₀}, C — число событий, консолидированных во снах (сон длиной k консолидирует события с прошлого сна с вероятностью p(k));
  - когда быстрая память погасла, а в окне 32 такта есть событие, считывание даёт верный знак с вероятностью q, иначе вид случайный;
  - C₀ ∈ {30, 100, 300}.

### Эвристики
| Политика | Что делает |
| --- | --- |
| не спать никогда | только быстрая память |
| спать каждые N тактов | N ∈ {25, 50, 100, 200, 400, ∞} от пробуждения |
| спать при давлении ≥ θ | θ ∈ {1, 2, 3, 4, 6, 8, 12, 16, 24, 32, ∞} |
| длина сна | k ∈ {5, 10, 20, 40} для обеих сеток |
| оракул знака | всегда знает знак, не спит |
| «спать бесплатно» | как «давление ≥ θ», но консолидация мгновенная, полная, вне времени (как проигрывание в паузе сейчас); лучшая по θ |

### Критерии прохождения (основная конфигурация M1, τ = 10, κ = 10)
k — лучшая по max F на сетке, отдельно для θ и для N. Все разности — попарные по 200 жизням: z = среднее / (ст. откл. / √200).
1. **Компромисс есть:** максимум F по θ — **внутри** сетки (не θ = 1 и не θ = ∞), и разности «максимум − оба края» различимы: z ≥ 3 с каждой стороны. То же для N (края N = 25 и N = ∞) — второе условие.
2. **Цена времени реальна:** лучшая «спать бесплатно» лучше лучшего платного сна, z ≥ 3.
3. **Правило 6:** путь от «не спать» (θ = ∞) к оптимуму θ* монотонен по средним хотя бы с одной стороны (от θ = ∞ вниз к θ* или от θ = 1 вверх к θ*).
4. **Сигнал/шум шагов θ для ES при 4 жизнях на особь:** для каждого соседнего шага на пути — среднее попарной разности / (ст. откл. / √4). Указывается; ориентиры — память во `flip-2` ≤ 2 (ES не нашла), исходная арена 18,5.
5. **Затухание быстрой части:** при τ = 10 быстрая память держит знак не дольше одного разворота (средний промежуток 100 тактов) — выполнено по построению. Проверяется ещё чувствительность по τ: при каком τ выгода сна исчезает.

Среда проходит, если выполнены 1 (для θ), 2 и 3. Условие 1 для N, а также 4 и 5 — сведения для решения о пилоте. M2 — описательно; она отвечает на вопрос, сохранится ли компромисс у агента, у которого медленная память — правило, а не знак.

**Вердикт по пререгистрации: среда не проходит** (не выполнен критерий 1). ES-пилот не обоснован; слот бюджета не израсходован.

### Почему (выведено, не проверено)
1. **В M1 сон даёт только то, что уже даёт быстрая память, — последний исход.** Выгода сна существует лишь из-за искусственного затухания быстрой части, а сон сам стоит времени, за которое быстрая память гаснет ещё раз.
2. **Цена сна — не только время, но и энергия при поглощающей смерти.** 10 тактов сна стоят 0,12 энергии — треть пищи; при выживании 8 % любое время без еды убивает. «Время как ресурс» здесь превращается во «время как риск смерти».
3. **M2 (медленное считывание как правило, описательно) даёт слабый внутренний максимум.** Сон приносит навык, а не скоропортящийся факт:

   | C₀ | лучшая точка (k, θ) | F | «не спать» (z) | θ = 1 (z) |
   | --- | --- | --- | --- | --- |
   | 30 | (10, 12) | 0,412 | 0,342 (2,4) | 0,102 (9,9) |
   | 100 | (5, 24) | 0,371 | 0,342 (1,3) | — |
   | 300 | — | ≈ «не спать» | — | — |

   - Выигрыш у «не спать» и при C₀ = 30 ниже порога z 3. SNR шагов θ при 4 жизнях на особь ≤ 0,4 — ES такой путь не найдёт.

### Что могло бы дать компромисс (ждёт решения Егора; каждый пункт — изменение среды или агента, новая пререгистрация)
- **Сон дешевле по энергии** (во сне обмен ниже — биологически так): тогда цена сна — только упущенная еда, а не смерть.
- **Нужда во сне изнутри агента:** конечный буфер — неконсолидированный опыт затирается. Давление сна тогда значит «теряю опыт», а не «знак устарел».
- **Медленно меняющееся правило** (например, сезонная смена соответствия признаков видам): считывание приходится переучивать — регулярная нужда во сне для агента, у которого медленные веса — правило (как у LM-агента).
- **Мягче выживание** (меньше дрейф или больше предметов), чтобы F мерила эффективность, а не долю выживших.

**Оценка ES-пилота на 5090** (если среда будет переделана и пройдёт проверки):
- 32 особи × 4 жизни × 1000 тактов = 128 тыс. строк-тактов на поколение; при ≈ 0,3 мс на строку-такт в большом пакете (замер A18) — ≈ 40 с на поколение плюс проигрывание во снах.
- 60–100 поколений ≈ 45–75 мин, с тестом на 10 посевах ≈ 1–1,5 ч ≈ $0,5–0,7.

## S2 — пререгистрация (записано до расчёта)
**S2 — последний вариант среды со сном; если не пройдёт критерии — вывод: время как ресурс в этой постановке не возникает.** Решение Егора 2026-10-04.

Среда — `env_sleep2.py`, эвристики — `sleep2_precheck.py`, без ES и LM, CPU.

**Изменения против S1:**
- **Сезоны.** В случайные такты (1/300 за такт) один из двух присутствующих видов исчезает, появляется новый вид со своим символом, его роль — монетка. Знак разворачивается внутри сезона (1/100 за такт). Предметы нового вида — на новых местах.
- **Конечный буфер агента.** Неконсолидированный опыт старше B_max тактов затирается; основное B_max = 200, чувствительность 100 и 400.
- **Обмен во сне ниже:** дрейф во сне 0,3 обычного; чувствительность 0,1 и 0,6.
- **Мягче выживание.** Смерти нет, энергия не ниже 0; F = средняя энергия за жизнь (время на нуле — штраф через саму среднюю). L = 1500 тактов (≈ 5 сезонов), 200 жизней на точку, посевы 50000+i.

**Калибровка скорости медленного обучения** (`calib_c0.py` → `results_sleep2/calib_c0.json`, до этой записи).
- Источник — записанный опыт агента A15 (`results_evo/record`, 26 жизней × 100 эпизодов, lm pretrained c). Медленные веса учатся проигрыванием по правилу A17 (η 1,9996, B 50, K 10) на эпизодах 0–49 по одному. После каждого эпизода замороженная голова оценивается на эпизодах 50–99 того же посева: точность «A — пища» против истинного знака на информированных тактах.
- Кривая (среднее по 26 посевам), точность по числу эпизодов проигрывания:

  | эпизодов | 1 | 3 | 5 | 10 | 20 | 50 |
  | --- | --- | --- | --- | --- | --- | --- |
  | точность | 0,554 | 0,615 | 0,649 | 0,707 | 0,795 | 0,896 |

  0,85 — за **31 эпизод ≈ 198 событий** (по посевам 15–43 эпизода, один не дошёл).
- По сетке A15 (η 1, K 3) 0,85 за 50 эпизодов не достигается (0,835).
- Эвристика M2: 0,5 + 0,5·(1 − e^{−C/C₀}) = 0,85 → **C₀ = 198 / ln(1/0,3) ≈ 165 событий**. Считывание — по символам, а калибровка шла на двух видах, поэтому на вид **C₀ᵥ ≈ 82 события**. Переноса между видами нет — допущение.

**Модель агента:**
- быстрая память — какое гнездо пища, по последнему исходу; держится τ = 10 тактов;
- медленное считывание по символам: q_X = 1 − e^{−C_X / C₀ᵥ}. Работает, когда быстрая память погасла, а в окне 32 такта есть событие с ещё присутствующим видом: с вероятностью q_X даёт вывод из этого события, иначе случайный выбор;
- консолидация в конце сна длиной k — с вероятностью 1 − e^{−k/κ}, κ = 10; учитываются только события не старше B_max;
- «бесплатный сон» — мгновенная полная консолидация.

**Прогноз (выведено до расчёта).** Вид живёт около двух сезонов (~600 тактов), это ~25–30 событий с ним. При C₀ᵥ ≈ 82 качество считывания вида к его исчезновению ≲ 0,3. Медленное обучение откалибровано как слишком медленное для смены видов, так что выгода сна может быть малой.

**Эвристики и сетки** — как в S1: never; every N ∈ {25, 50, 100, 200, 400, ∞}; pressure θ ∈ {1, 2, 3, 4, 6, 8, 12, 16, 24, 32, ∞}; k ∈ {5, 10, 20, 40}; оракул; бесплатный сон.

**Критерии** — те же, что в S1, основная конфигурация выше:
1. максимум F по θ внутри сетки, z ≥ 3 к обоим краям;
2. бесплатный сон лучше лучшего платного, z ≥ 3;
3. путь по правилу 6;
4. сигнал/шум шагов θ при 4 жизнях на особь — указать.

Проходит, если выполнены 1, 2, 3. Чувствительность (B_max, обмен во сне, τ, C₀ × 0,5 / × 2) — описательно.

## Перенос: нелинейная голова и несколько наборов символов — пререгистрация (записано до расчёта)
Дополнение Егора 2026-10-04, п. А. Код — `transfer_mlp.py`, ноутбук.

**Повод.** Pacela et al., «Stop Probing, Start Coding» (ICML 2026, arXiv 2603.28744): при суперпозиции признак, линейный в пространстве понятий, может быть нелинейно отделим в активациях, особенно вне распределения. Перенос X → Y линейной головой (0,525) не доказывает отсутствия абстрактного кода.

**Наборы символов видов.** Меняются только токены видов A / B; ' none' и символы энергии те же; все однотокенные.
- Обучающий пул (5): c ' A'/' B', p1 ' cat'/' table', p2 ' lamp'/' cloud', p3 ' violin'/' carpet', p4 ' bottle'/' feather'.
- Тестовые (3, никогда не в обучении и не в подборе): t1 ' candle'/' tunnel', t2 ' basket'/' mirror', t3 ' jacket'/' bridge'.

**Пары.** Жизни A11 «all, full» (онлайн-голова от тела, η условия), 10 жизней (посевы 1–10) на каждый набор пула, одна сеть на все жизни условия. Стандартизация одна — по набору c.

**Тест** — вне контура: слепая политика, 100 эпизодов 999000+k, точность «A — пища» на информированных тактах, по каждому набору.

**Повторы.** r = 1..10 и k ∈ {1, 2, 3, 5}: k наборов пула (случайно, при k = 5 — все), пары из жизни r каждого набора. **Всего 3000 пар поровну между наборами** — объём данных не растёт с k, растёт только разнообразие.

**Головы:**
- **линейная** — логистическая регрессия L2, λ по CV с группами-эпизодами (как A14);
- **MLP** — один скрытый слой 256 (ReLU), AdamW, lr 1e-3. Затухание весов из {1e-4, 1e-2, 1} и ранняя остановка (терпение 10 эпох, до 300) — по точности на отложенных 20 % эпизодов **обучающих** пар. Тестовые наборы в подборе не участвуют.

**Меры.**
- Точность в распределении — среднее по k обучающим наборам; на новых — среднее по трём тестовым.
- **Перенос T = (на новых − 0,5) / (в распределении − 0,5).**
- Критерий переноса (как раньше) — на средних по повторам: на новых ≥ 0,8 × (в распределении − 0,5) + 0,5.

**Основная семья** (lm pretrained c; Холм по двум; точные парные перестановочные тесты по 10 повторам, двусторонние; минимально возможное p — 0,002):
1. T(MLP, k = 1) − T(линейная, k = 1);
2. T(MLP, k = 5) − T(MLP, k = 1).

**Толкование (записано заранее):**
- линейная не переносит, MLP переносит — абстрактный код есть, но не линейно доступен;
- перенос растёт с k — абстракция возникает из разнообразия видов;
- ни то ни другое — код привязан к символам, и вывод становится надёжным.

Описательно: lm random c (одна случайная сеть на все жизни — отступление от A14, где сеть сеялась от посева), quad (новые символы — новые случайные строки проекции).

**Решение по ES-пилоту S2 — только после этого пункта.** Если перенос есть, компромисс сна у настоящего агента меняется с опытом, и пилот надо переконструировать.

**Проверки до записи** (числа в выводы не идут):
- на синтетике (один линейный признак в 768 измерениях, 2400 примеров) MLP — 0,65, линейная — 0,89: малые данные высокой размерности MLP невыгодны. Поэтому ранняя остановка и выбор затухания — по точности, а не по потере;
- на парах A14 одной жизни (в распределении, отложенные эпизоды): MLP 0,967, линейная 0,91.

**Время:** жизни пула 3 условия × 5 наборов ≈ 40 мин, тестовые траектории ≈ 10 мин, головы ≈ 40 мин.

## Настоящий агент в S2 — сетка порогов сна без эволюции: пререгистрация (записано до расчёта)
Решение Егора 2026-10-04. Код — `sleep_agent.py`. Среда — `env_sleep2.py` без изменений: L = 1500, сезоны 1/300, развороты 1/100, обмен во сне 0,3, смерти нет, F = средняя энергия. В `ATTEMPTS.md` — пилот настоящего агента, не новая среда.

### Агент
- **LM** — Pythia-160M, предобученная, fp32. Вход: BOS + окно 32 такта × (символ съеденного вида или ' none'; символ энергии ' up' / ' down' / ' same') + символ давления сна + символы двух присутствующих видов (гнездо 0, гнездо 1). Голова читает последнее скрытое состояние (на символе гнезда 1).
  - **Символы видов** — однотокенные слова из пула 24 (' candle' … ' mountain'); у каждой жизни своя перестановка пула, номер вида → слово.
  - **Давление сна** — один символ в конце: ' north' / ' east' / ' south' / ' west' для 0 | 1–2 | 3–5 | ≥ 6 (пороги — из `env_sleep.py`).
  - Пулы не пересекаются между собой и с символами событий; однотокенность проверена токенизатором.
- **Быстрая память — только окно LM**; быстрых весов нет (основная конфигурация).
- **Медленная голова** — линейная по стандартизованному скрытому состоянию.
  - Выбор: logit > 0 — гнездо 0, < 0 — гнездо 1; = 0 (ни разу не обучалась) — к ближайшему предмету любого вида.
  - Стандартизация — по случайному поведению в S2 (40 жизней × 200 тактов).
  - Учится **только во сне**: проигрывание буфера, нормированный шаг по мини-пакетам 32, η = 1,9996 (A17; устойчиво при 0 < η < 2, правило 12).
  - **Число проходов — min(k, 10): один проход на такт сна.** Так длина сна связана с объёмом консолидации; при k = 10 — как в A17.
  - Метки — тело: «гнездо 0 — пища» по последнему исходу. Метка сохраняется до следующего события, в том числе через смену вида, — как в S2.
- **Буфер** — пары (z, метка) бодрствующих тактов с меткой, не старше B_max = 200 тактов. Проигранные во сне удаляются (S2: «переработанный» опыт). Это отличие от A17, где буфер в 50 эпизодов проигрывался повторно.
- **Сон** — правило: давление ≥ θ → спать k тактов.
- **Ориентиры:**
  - «бесплатный сон» — то же проигрывание (10 проходов) мгновенно и без сна, при θ = 2 (лучший у эвристики);
  - оракул знака;
  - «не спать» = θ = ∞.

**Известная особенность основной конфигурации (записано до расчёта).** Без быстрых весов «не спать» значит «считывания нет вообще»: голова не обучена, и агент выбирает ближайший предмет. P1 поэтому проверяет «консолидация во сне окупается против отсутствия считывания», а не «сон против быстрой памяти», как в эвристике (там «не спать» имело быструю память τ = 10).
