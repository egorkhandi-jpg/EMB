## Appendix A 复现与分词器迁移

**模型。** Qwen2.5-1.5B（`Qwen/Qwen2.5-1.5B`）和 OLMo-2-1B（`allenai/OLMo-2-0425-1B`），两者均无访问限制。Pythia-1B 作为参照，在同一台机器上经由同一份迁移后的代码运行；它不属于复现检验族。对于每个模型，随机权重（random weights）对照使用相同架构、对每一组重新设定种子的网络（词义探针使用一个网络，种子 1），并将输入嵌入重新缩放到预训练（pretrained）嵌入的平均行范数。所有运行均使用 fp32 并禁用 TF32。

**起始标记（start token）。**
- 每个模型的文档结束标记 `<|endoftext|>` 被用作起始标记：0（Pythia）、100257（OLMo-2）和 151643（Qwen2.5）。
- 在 Pythia 和 OLMo-2 中它是 BOS 标记；Qwen2.5 默认没有 BOS。

**单标记词。**
- 协议使用的每一个词在全部三种分词器中都是带前导空格的单个标记。这涵盖事件符号、两组任意词以及所有词义词池（30 个食物词、30 个有害词、30 个中性词和 11 个直接词）。不需要任何替换。
- 标记编号取自各自的分词器：事件符号 A, B, none / up, down, same 的编号为 362, 425, 6857 / 705, 1495, 1852（Qwen2.5）和 362, 426, 7000 / 709, 1523, 1890（OLMo-2）。
- 在 Pythia 中它们为 329, 378, 5293 / 598, 1066, 1072，与原始脚本中的常量完全一致。

**核验。**
- 对三种分词器，五个协议的所有输入都经过解码和检查。
- 隐藏状态读取为 `base_model(...).last_hidden_state`（在最终归一化之后）。在检验族之外的一个模型上，它与 `hidden_states` 的最后一个元素完全一致，logit 与隐藏状态 × 输出嵌入完全一致。
- 经由迁移后代码运行的 Pythia-1B 复现了原始结果：

| 协议 | 迁移后的代码 | 原始结果 |
| --- | --- | --- |
| 词义探针：种类位置 / 最终位置 / 直接词 | 0.983 / 0.526 / 1.000 | 0.983 / 0.526 / 1.000 |
| 合成窗口：冲突窗口上的 d，有 / 无绑定 | −0.262 / −0.284 | −0.262 / −0.284 |
| 零样本回答 AUC / 探针 AUC | 0.61 / 0.99 | 0.61 / 0.98–0.99 |

**协议与检验族。**
- **R1：** 符号探针（probe），事件词。
- **R2：** 任意词，非劣效（non-inferiority）界值 0.02，并要求优于随机权重。
- **R3：** 表达差距，三个问题。
- **R4：** 按位置的词义，阈值 0.9 和 0.8。
- **R5：** 合成窗口，向经验的偏移，分别相对于置换结果和相对于随机权重。
- **检验：** R1、R2 和 R5 使用在 10 组上的单侧精确配对置换检验（permutation test），并在六项检验（三项检查 × 两个模型）上进行 Holm 校正（Holm correction）。R3 和 R4 与原始报告中一样为阈值。

**相对于原始协议的偏离（在计算之前记录）。**
- R1 直接以单侧方式检验"预训练 > 随机"。原始的 A3 检验是双侧的，针对的是这一差值相对于投影器接口的变化。
- 与原始的 A3/A4 一样，探针特征在每一折的训练部分上标准化。
- 在 R3 中，探针在三个问题各自的位置上拟合。

**结果。**
- **两个新家族：** R2–R5 得到复现。
- **R1：** 在 OLMo-2 上得到复现。在 Qwen2.5 上，使用原始事件词时没有复现，但使用任意词时得到复现。

**计算。** 整个检验族使用一块租用的 RTX 5090。队列运行 2.56 h，没有失败；实例总共租用 3 h 16 min，包括模型下载。
