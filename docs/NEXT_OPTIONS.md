# Варианты следующего шага (2026-10-04; обновлено 2026-10-05, v-final-2)

**Итоговый отчёт v-final-2** (`docs/FINAL_REPORT.md`, п. 11) — открытые вопросы без рекомендации: узкий вопрос C (связывает ли модель смысл слова с опытом тела: 6.9B, вопрос после окна, правдивые и лживые подсказки); D (консолидация против обучения на ходу); необратимый вред; обучаемая запись в слот; звено 4 после обучения языкового канала; иной интерфейс для геометрии (остаток после вычитания — с оговоркой о тавтологии); этап 4. Бюджет среды: израсходовано 0 из 2.

**A. Звено 4 — выполнен (2026-10-04, A22, `docs/RESULTS_2026-10-04_report.md`).** Знак в представлении есть (зонд 0,98–0,99), языковому каналу без обучения доступен слабо (zero-shot AUC 0,61); few-shot — копирование ответа примера. **Продолжение A23 (5090):** с примерами из других эпизодов обучения в контексте нет (AUC ≈ 0,5, 160M и 1B) — звено 4 без обучения языкового канала отрицательно на этих размерах.

**B. Звено 6 — закрыто (2026-10-04, Т1 и Т2, только эвристики, `docs/RESULTS_2026-10-04_toxin.md`).** Вместо «двух потребностей» проверялась среда «скрытый токсин» (вынужденная модель себя). Токсин-1: барьер 4–6 %, но его берёт память в окне (таймер 7–10 тактов, последнее событие). Токсин-2 (медленное всасывание; последняя версия по правилу остановки): память дальше окна нужна, но термостат по энергии без памяти даёт 96–98 % оракула, модель себя добавляет 2–4 %, путь к ней не монотонен; не прошла ни одна из шести пар. По правилу остановки: в минимальном теле вынужденная модель себя не возникает, термостата достаточно. Столбец B ниже — для истории.

**G. Тезис 5 (геометрия «я / мир») — закрыто (2026-10-05, Г1–Г3, A25, `docs/RESULTS_2026-10-05_geometry.md`).** Г3 «назови живого» (последняя версия): этап 1 пройден — без опоры на мир знание своих действий необходимо (0,985 против угадывания), с ростом опоры одометрия догоняет; этап 2 — Pythia-160M без обучения через азбуку событий мир от себя не отделяет (G1, G2, G3, Q-R1 — ничего), с оговоркой, что азбука теряет информацию (ориентир 0,62). Ниже — прежняя запись о Г2.

**G (Г2, для истории). Этап 1 не пройден (2026-10-05, Г1, Г2, только эвристики).** В среде `env_geo.py` разделение я / мир достигается без знания своих действий: лучшая база — исключение по касанию пустышки (не зависит от опоры на мир), при богатой опоре — зрительная одометрия; знание своих действий — лучший дистальный способ и сильнее всего там, где ориентиров нет (против одной одометрии, описательно), но критерии не пройдены; грубая модель себя хуже никакой. Этап 2 (LM) не запускался. Возможные изменения среды (убрать путь касания, мягче грубость модели, задача «назови живого») — в отчёте, по решению Егора.

**C. Шлюз — выполнен (2026-10-05, A24, `docs/RESULTS_2026-10-05_meaning.md`, RTX 5090).** Pythia 1B / 2.8B / 6.9B знают «еда / вред» по словам без прямых названий (зонд ≈ 1,0, s(w) 0,96–0,98), и в окне событий это знание есть на позиции символа вида (0,98–1,00), но не на последней позиции окна, которую читает голова стенда (0,53–0,62). По пререгистрации — K1 без K2: перед средой с подсказками нужен другой интерфейс (слова видов в коротком предложении или голова по позициям символов видов). Решение о слоте — за Егором.

**C, узкий вопрос — выполнен (2026-10-06, A26, `docs/RESULTS_2026-10-06_bind.md`, RTX 5090).** Pythia 1B–6.9B отвечают «какой вид — еда» по смыслу слова без опыта (M 0,83–0,95); при конфликте смысла и опыта ответ сдвигается только через частоту упоминаний (копирование при отборе выживших), связки «слово вида ↔ исход» нет (на окнах с поровну съеденными видами B ≈ 0 в 5 из 6 ячеек; намёк — 6.9B в предложениях). Для среды с подсказками это значит: смысл слова у модели есть и в ответ доходит, но опытом тела без обучения не переписывается. Открыто (не предлагается, только перечислено): та же мера с вычитанием копирования до расчёта и с политикой без отбора выживших; модели крупнее 6.9B.

**C, последняя проверка — выполнена (2026-10-06, A27, раздел A27 в `docs/RESULTS_2026-10-06_bind.md`, RTX 5090).** Синтетические окна без частотного канала: исход «H2 без H1». Сигнал «слово вида ↔ исход» у Pythia 1B / 6.9B есть и переживает удаление частот (значим во всех условиях и интерфейсах, у случайных — ноль), но мал — 4–11 % от смыслового эффекта, ответа не меняет; на нейтральных словах AUC 0,509. Правило остановки («ни H1, ни H2») формально не сработало.

**Ось 1 — «спектр памяти агента повторяет спектр временных масштабов мира» (2026-10-06, `docs/RESULTS_2026-10-06_spectrum.md`).** Этап 1, версия 1 (только эвристики, CPU, `env_spectrum.py`) не прошла: 0 из 16 конфигураций — один след знака закрывает 93–98 % разрыва «без памяти → оптимум», подобранные медленные постоянные в 6–30 раз короче масштабов мира; многослойная память выигрывает только при редких свидетельствах и мало (≤ 7 %). По правилу остановки допускается одна версия 2 — решение Егора; этап 2 (настоящий агент: окно LM, пластичная голова, медленные веса от проигрывания) — только по решению Егора, слот бюджета.

**C — закрыт решением Егора (2026-10-06).** Вариант C — закрыт решением Егора (правило остановки формально не сработало: исход «H2 без H1»). Pythia 1B–6.9B использует смысл слов вида (M выполнено везде) и копирует чаще упомянутое слово (A26). След связки «слово вида → исход» из опыта в окне есть и устойчив при удалении частотного канала (A27: H2, Холм 0,002; у случайных моделей ноль), но составляет 4–11 % от эффекта смысла и ответа не меняет: при конфликте смысл перебивает опыт в той же доле окон, что и без связки. С размером 1B → 6.9B не растёт. Намёк A26 (6.9B, предложения, +0,43 при равных упоминаниях) в чистой конструкции не подтвердился (+0,02).

**E. Итоговый отчёт — выполнен (2026-10-05, `docs/FINAL_REPORT.md`, метка `v-final-1`).** Открытыми остаются C, D, геометрия (звено 5) и необратимый вред (после закрытого звена 6).

**F. Слот — выполнен (2026-10-04, п. 22, `docs/RESULTS_2026-10-02_slot.md`).** Запись по правилу органа читается замороженной головой и полностью заменяет быструю память за окном (1,000 при k > 4; Холм 0,003). Но результат почти тавтологичен: запись кодирует ответ, случайная LM читает её так же. Открыт вопрос «научится ли агент сам решать, что писать».

Решение — за Егором. Рекомендации нет, только сравнение.

**Бюджет.** По правилу остановки (`docs/PLAN.md`) осталось **2 слота новых вариантов среды**. Слот расходуется при запуске на варианте пилота с обучением; эвристические проверки его не расходуют.
