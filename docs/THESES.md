## 1.4 Выведено, не проверено (кандидаты в вопросы)
- **Поведение берёт на себя часть работы внутренней модели — три механизма в четырёх случаях.** Выведено. (а) Обход через обратную связь от собственных действий (A13): сырое окно, «проиграл — переключись» (0,759 → 0,570 вне контура); случайная LM читает знак через поведение (0,670 → 0,513). (б) Регуляция темпом (Т1, Т2): термостат по энергии 96–98 % оракула. (в) Исключение касанием (Г2): коснулся пустышки — живой другой (NOEFF 47,1, не зависит от опоры на мир).
- **Время как ресурс требует медленной структуры мира.** Выведено из A15 и п. 21: проигрывание закрепляет устойчивое считывание, но в S2 закреплять долго нечего, и онлайн-слежение выигрывает. Что обучение на ходу портит устойчивое знание — **спекуляция** (проверяет вариант D).
- **Модель себя нужна при необратимом вреде, опережающем регулируемую переменную.** Спекуляция — гипотеза о границе: Т1–Т2 (вред обратим, термостата хватает) с одной стороны, S1 (поглощающая смерть делает ошибку необратимой; модель себя там не проверялась) — с другой.
- **Полезность неточной модели себя зависит от цены ошибки.** Спекуляция по Г2–Г3: при восприятии частичная модель монотонно полезна (Г3: ±10 % — 0,88, ±30 % — 0,67), путь к ней есть; при добывании та же неточность вредна (Г2: 31 против 39 у R0) — ошибка восприятия превращается в ошибку действия; переоценка связи «действие → следствие» через общее движение мира быстрее при богатой опоре (Г2, EFFA) — возможный механизм калибровки модели себя по миру.
- **Информация присутствует, но не направлена туда, где её читают.** Выведено по двум опытам одинаковой структуры: знак тела в представлении есть (зонд 0,98–0,99), но через слова не выходит (A22, A23); смысл слова есть на его позиции (0,98–1,00), но не доходит до последней позиции окна (0,53–0,62) (A24).
- **Аппарат силён в поиске редких событий среди фоновых символов.** Выведено по A8: преимущество есть только у азбуки событий, не у азбуки ощущений. Не проверено.
- **Редкие развороты учат считывание излишней уверенности.** По H5: копия h_lo слабее во всех средах, включая свою. Калибровка уверенности не мерилась — это толкование, не наблюдение.
- **Профиль компетентности копии идёт за объёмом и разнообразием информативного опыта, а не за «своей» средой.** Матрица п. 20: копия dense — лучшая и в среде частых разворотов.
- **Копии сводятся к одному решению, потому что у задачи один правильный ответ** (п. 19). «Особь» в поведении требует задачи с несколькими равноценными решениями.
- **Звенья 2 и 3 связаны**: движение проектора к словарю может быть путём к знаниям. Спекуляция; проверка C (A6) неинформативна.

## Тезисы (сжато; полная версия — документ «Воплощённый LLM-агент: тезисы, стенд, задачи»)

Статусы: установлено / выведено, не проверено / спекуляция.

### Исходные
1. LLM — один большой кадр: всё состояние — текст контекста, внутреннего состояния вне текста нет. Установлено.
2. Порядок без длительности: без входа ничего не меняется. Установлено.
3. Веса — застывшая запись; модель синтезирует, но не учится. Установлено.
4. Время даёт гомеостаз: потребность — отклонение, нарастающее без действия; отсюда история и будущее, которое можно потерять. Выведено.
5. Геометрия даёт границу, позицию и разделение «я / мир» (мир — инвариант при собственных перемещениях). Выведено.
6. У LLM геометрия представлений, но не геометрия существования. Установлено.
7. Если геометрия и время составляют сознание, ИИ — его язык, след существ, у которых они были. Спекуляция.
8. Язык описания внутренней стороны ищется через инварианты — медленные переменные. Спекуляция.

### Конструкция
~~Текстовый канал = нынешнее положение LLM~~ (было; ИЗМЕНЕНО 2026-10-02 по п. 4). **Канал событий словами — словарь тела из существующих токенов, а не описание мира; знания модели доступны только через вход из её распределения.** ПОПРАВЛЕНО 2026-10-02 по A: часть «из распределения словаря» неверна — шесть случайных векторов нормы токена вместо слов в предобученном трансформере дают лучший результат (0,984 против 0,950 со словами), произвольные слова лучше осмысленных (+0,016, Холм 0,004; на уровне представления; в поведении перевес набора c_arb1 не воспроизвёлся на c_arb2 — A13, так что в поведении — «не хуже»), предобученные эмбеддинги в случайном трансформере не помогают (0,784). Действующая формулировка: **предобученный аппарат трансформера включается на дискретной последовательности событий из малого алфавита (с BOS), независимо от смысла символов и их принадлежности словарю; на непрерывных проекциях ощущений — нет** (выведено по A; механизм — копирование/индукция по повторам — не проверен). Исходное обоснование по п. 4: со случайным проектором без BOS предобученная Pythia-160M хуже случайной (−0,054), с BOS — почти равна (−0,008), с событиями такта однотокенными словами + BOS — лучше (0,950 против 0,813, Холм 0,004). Сырые данные = шум. Исходный третий путь: зашитый орган чувств (инварианты, тренды) → проектор в эмбеддинги вне словаря, отбираемый эволюцией по выживанию тела — именно он, по п. 4, отключал предобученный аппарат. Две скорости: быстрый зашитый рефлекторный слой и медленная LM.

**Эволюция настраивает правило обучения, считывание выучивается при жизни** (выведено по A9–A10, решение Егора 2026-10-03; проверка — повтор режима i с нормированным шагом). **Проверка A11 (2026-10-03): во второй части не подтверждено** — нормированным дельта-правилом от тела замороженное считывание при жизни не выучивается лучше ES и без преимущества предобученной; при жизни выучивается онлайн-подстройка к эпизоду (быстрая память), но она не переносится в постоянное считывание. ES с простым шагом (без Adam) медленно находит считывание сама (A12). A9: ES с Adam не удерживает даже готовое считывание (дрейф), простой малый шаг удерживает, но не улучшает; A10: онлайн-правило от тела при устойчивом шаге не проверялось. Если считывание выучивается при жизни из сигнала тела, то эволюции остаётся выбирать правило и его параметры (скорость, что считать меткой), а не веса головы. **Проверка `v3-replay` (A14–A15, 2026-10-04): вторая часть подтверждена в изменённой форме** — считывание выучивается при жизни из сигнала тела, если медленные веса учатся проигрыванием опыта в паузе после эпизода, а не онлайн: замороженная голова 0,839 (вне контура 0,831) против 0,576 у онлайн-правила; метки тела годны (пакетная регрессия 0,902). Преимущество предобученной при этом есть (+0,145 к случайной, +0,097 к quad). Проигрывание опыта и консолидация медленной системы по записям быстрой — **известный принцип** (дополняющие системы обучения: McClelland, McNaughton, O'Reilly 1995; проигрывание опыта в RL), здесь переоткрыт на стенде, а не открыт. **Новое на стенде** (установлено, A14): учитель-тело лучше оракула — пакетная регрессия на метках тела читает знак вне контура на 0,902, на истинном знаке — 0,862, потому что метка тела согласована с наблюдаемым (после разворота, до следующего события, метка остаётся старой, как и всё, что видно на входе). Первая часть («эволюция настраивает правило») не проверялась. **Проверка `v3-evo` (A17, п. 17, 2026-10-04): первая часть поддержана в слабой форме** — ES по наблюдаемой агентом приспособленности (предсказание меток тела на следующей жизни) подбирает параметры проигрывания лучше ручной сетки, и это переносится в контур (+0,049 вне контура, Холм 0,004; преимущество предобученной +0,256). Но выбор тривиален: все параметры ушли на верхние границы области поиска («учиться в паузе как можно больше»), случайный поиск того же бюджета почти так же хорош (+0,011), а результат (0,880 вне контура) — на уровне пакетной регрессии до сходимости (0,902). Нужна ли эволюция сверх правила «консолидировать до сходимости» — не показано.

**Азбука событий** (выведено по A8, не проверено): дискретизация состояний (один символ кластера на такт) помогает обеим моделям одинаково; преимущество предобученной есть только при азбуке событий (интерфейс c — вид и исход отдельными символами). Гипотеза: аппарат силён в поиске редких событий среди фоновых символов.
**Индукционные головы — опровергнуто в простой форме** (A7): удаление верхних 8 голов по оценке сопоставления префикса повышает чтение знака (0,950 → 0,984, ≈ байесовский потолок 0,99), у случайной LM без изменений.

**Звенья 2 и 3 связаны** (спекуляция; проверка C — округлённый проектор — неинформативна: округление теряет информацию у обеих моделей, 0,66 против 0,87; по A важнее не «слова», а дискретизация ощущений в малый алфавит). Если знаниям модели нужен вход из её распределения, то движение проектора к словарю («проектор переизобретает слова», звено 3) может быть не провалом, а путём к знаниям.

**Уникальность особи** (опыт с копиями, `v4-copies`, 2026-10-04). Копии одного агента, прожившие разные жизни (разная частота разворота, плотность предметов), по поведению не становятся разными особями сверх случайного разброса — установлено для 8 посевов, H1 и H2 отрицательны. История среды записана в медленных весах (1 − cos, 8/8, переживает возврат), но в направлениях, почти не влияющих на выбор. Выведено, не проверено: у задачи «знак эпизода» один правильный ответ, и хорошее представление вместе с консолидацией до сходимости сводят любую историю к нему. «Особь» в поведении требует задачи с несколькими равноценными решениями. Вопрос уникальности — о вырожденности задачи не меньше, чем об агенте. У случайной LM (слабое представление) след среды в поведении есть, но обратим (3 посева, наблюдение). **Латентная индивидуальность (A19):** и на незнакомых состояниях (три разворота, виды 3:1, редкие предметы) копии из разных сред расходятся по выбору не больше, чем от случайного опыта (H3 не выполнена). Описательно (вне семьи): на трёх разворотах копия, жившая с частыми разворотами, точнее (+0,026, 8/8), а с редкими — хуже (−0,014). История может проявляться в направлении компетентности на незнакомом, а не в величине расхождения. **Проверено (H4, H5, 2026-10-04, новые посевы, ноутбук): установлено** — копия с частыми разворотами сильнее на ещё более частых (+0,030, 8/8), с редкими — слабее (−0,015), семья с H5 выполнена (Холм 0,012). Индивидуальность копий — **профиль компетентности**, а не расхождение выбора. По матрице «копия × среда» профиль идёт за объёмом и разнообразием информативного опыта (копия dense — лучшая и в среде частых разворотов; копия h_lo слабее везде), переживает возврат в общую среду (вне контура). В контуре — слабее.

**Время как ресурс (S1, S2).** В S1 платный сон хуже «не спать». В S2 (сезоны, конечный буфер, дешёвый сон, без смерти, C₀ откалиброван по A17) компромисс есть: внутренний максимум, z 3,4 к «не спать». Но выигрыш ≈ 5 %, он исчезает при вдвое более долгой быстрой памяти или вдвое более медленном обучении, а сигнал/шум шагов θ при 4 жизнях на особь ≤ 0,34. Звено 1 в сильной форме (время, которое можно потратить и потерять) показано на эвристике, но слабо; для эволюции компромисс почти невидим. **Перенос считывания на новые символы (A20, A21):** у настоящего агента его нет — ни у линейной, ни у MLP-головы (T ≤ 0,17); код привязан к символам, лишь слабо обобщается с числом прожитых видов (рост с k только у предобученной). Предпосылка S2 верна. **Настоящий LM-агент в S2 (2026-10-04, RTX 5090): время как ресурс не подтверждено** — ни P1, ни P2: онлайн-обучение медленной головы без сна (A11) лучше любой политики сна (0,624 против ≤ 0,517) и даже бесплатного сна (0,543); среди политик сна «чем чаще, тем лучше». Выведено: в нестационарной среде выигрывает слежение, а не консолидация. Сон окупается, лишь если онлайн-обучение недоступно и консолидированное знание долго верно. Линия сна закрыта по правилу «S2 — последний вариант». Звено 1 в сильной форме на стенде не показано.

### Связанные работы
- Pacela et al., «Stop Probing, Start Coding», ICML 2026, arXiv 2603.28744 — при суперпозиции признак, линейный в пространстве понятий, может быть лишь нелинейно отделим в активациях, особенно вне распределения. Ограничение касается наших выводов **вне распределения**: перенос считывания на новые символы (A20 — линейная голова), копии на незнакомых состояниях (A19, H4, H5). Считывания **в распределении** (зонд п. 15, A14, A15–A17) не касается: там линейная голова и так близка к потолку. Отсюда проверка MLP-головой (A21).
- Обобщение связывания (переменная ↔ значение) растёт с разнообразием обучающих данных — общее наблюдение работ о композиционном обобщении. Мотивировка п. А (A21): вырастет ли перенос считывания на новые символы с числом разных наборов символов при том же объёме данных. Конкретной работы здесь не цитирую — не сверял.
- Lu et al., Frozen Pretrained Transformer (2021): замороженная GPT-2, обучаются вход/выход/нормализация — работает на чужих модальностях. https://arxiv.org/pdf/2103.05247
- Driess et al., PaLM-E (2023): сенсоры векторами в пространство эмбеддингов, но выход — текст, обучение на разметке. https://arxiv.org/pdf/2303.03378
- Zhong & Andreas, NeurIPS 2024, arXiv 2410.04368 — случайные трансформеры при обучении только эмбеддингов решают алгоритмические задачи, включая ассоциативное вспоминание по контексту; работают в низкоразмерных подпространствах. Наш П3: случайная Pythia без всякого обучения линейно хранит знак эпизода.
- Takagi, NeurIPS 2022, arXiv 2211.09817 — языковое предобучение не помогает трансформеру в офлайн-RL на Mujoco; предобученный усваивает меньше, чем случайный. Совпадает с нашим «предобученная ≤ случайная».
- Sun et al., COLM 2024, arXiv 2402.17762 — сверхбольшие активации почти не зависят от входа и работают как сдвиги; связаны со стоками внимания на начальном токене. Объясняет наш артефакт съёма (косинус 0,986 между состояниями при разных входах у предобученной Pythia-70M).
- Mirchandani et al., CoRL 2023, arXiv 2307.04721 — предобученные LLM продолжают последовательности токенов по контексту, частично даже на случайных токенах словаря.
- Позиционные работы о гомеостазе для LLM (2025): https://arxiv.org/html/2510.13845v1 , https://arxiv.org/pdf/2510.07117v3 ; контрпозиция: https://arxiv.org/html/2601.17588v1
Комбинация «замороженная LLM + проектор, отбираемый по выживанию + время через дрейф тела» в найденном не встречается (поиск не исчерпывающий).
