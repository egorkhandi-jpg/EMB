
## П. 4. Положительный контроль интерфейса — пререгистрация (записано до запуска)
**Вопрос.** Не в интерфейсе ли причина «предобученная ≤ случайная» (шкала: у 160M −0,053, p Холма 0,02)? Случайный проектор кладёт кадры вне распределения эмбеддингов; без BOS роль стока внимания (Sun et al. 2024), вероятно, достаётся первому псевдотокену.

**Модели.** Pythia-160M (основная — у неё значимое отставание) и 410M (описательно). fp32. Скрипт — `probe_interface.py`, зонд — `probe_fast.py` (сверка со старым решателем — ниже, до запуска).

**Условия** (окно N = 2, 8, 32; скрытое состояние последней позиции, последний и средний слой; цель — знак эпизода):
- **a** — исходный интерфейс: случайный проектор, 2 псевдотокена на такт (повтор для сверки);
- **b** — то же + настоящий BOS (`<|endoftext|>`, id 0) в начале окна;
- **c** — события такта однотокенными словами, без проектора, + BOS: съеденный вид (` A` / ` B` / ` none`), изменение энергии (` up` / ` down` / ` same`; порог |тренд| > 0,5 — дрейф −0,12, пища +3,4, яд −2,1);
- **d** — случайная LM в условиях a–c: те же номера токенов, своя случайная матрица эмбеддингов, приведённая к средней норме эмбеддингов предобученной.

**Данные.** Среда `flip-2` с разворотом (основная среда П3), политика, слепая к знаку. Посевы — 10 разных наборов по 200 эпизодов (посевы 31000 + 1000·s + k), одинаковые для всех условий; в a/b ещё и проектор от посева, у случайной LM — своя сеть от посева. Вторичная среда `flip-1` не гоняется: в c нет признаков навигации, а вопрос — об интерфейсе, не о среде. Справочно в каждом посеве — билинейная статистика и «съедено A − B».

**Гипотеза интерфейса поддержана**, если разность «предобученная − случайная» при N = 32 (последний слой) у 160M в b или c значимо выше, чем в a.

**Основная семья (Холм, 2 проверки)**, 160M, N = 32, последний слой: (b − a) и (c − a), где для посева s: Δ_x(s) = [пред_x(s) − случ_x(s)] − [пред_a(s) − случ_a(s)]. Точные парные перестановки смен знака по 10 посевам, двусторонние, α = 0,05 после поправки. 410M, средний слой, N = 2/8, кривые по тактам после события — описательно.
