# embodied-lm-stand

Замороженная LM в минимальном теле. Контекст, правила и окружение — в `CLAUDE.md`.

Окружение (с 2026-10-01): нативный Windows, системный Python 3.13 с `torch 2.11+cu128`,
`transformers`, `accelerate`; скрипты `.sh` — через Git Bash. WSL не нужен
(`setup_wsl.sh` оставлен на случай переезда на Linux).

Метки git: `v0-baseline-cpu` — пакет как пришёл (первая серия на CPU, fp32, случайная сеть
одна на все посевы); `v1-gpu-fp32` — fp32 на GPU, случайная сеть от посева, линейный
контроль. Результаты разных меток напрямую несравнимы.

Команды Claude Code:
- `/check-env` — проверка окружения и короткий прогон
- `/precheck` — предварительные проверки среды
- `/series <модель> <посевы> <пауза>` — серия с контролями, термозащитой и бэкапом
- `/summary [папка]` — сводка и механистический анализ
- `/next-step` — следующий шаг по плану (только план, без запуска)
